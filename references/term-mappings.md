# AI 高频词替换对照表（增强版）

## 一、AI 极致高频词（必须规避，出现即触发检测）

| 类别 | AI高频词 | 必须替换为 |
|------|---------|-----------|
| 总结 | 综上所述 | 删除或改为：以上分析指向一个判断 / 从已有证据看 / 综合来看 |
| 总结 | 总而言之 | 删除（直接进入结论） |
| 递进 | 首先……其次……最后 | 打乱顺序或删除标记词 / 改用：一个层面是 / 另一个视角看 / 归拢来说 |
| 递进 | 此外 | 删除或改为：另一个值得注意的点是 / 补充一组数据 |
| 递进 | 另外 | 删除或改为：还需要说的 |
| 递进 | 与此同时 | 删除或改为：同步观察到一个现象 |
| 强调 | 值得一提的是 | 改为：需要特别说明 / 此处有一个反直觉的发现 |
| 强调 | 值得注意的是 | 改为：不能忽略的一点是 / 一个意外发现 |
| 因果 | 因此 | 50%删除 50%改为：这指向 / 由此推论 / 所以（口语化） |
| 转折 | 然而 | 1/3改为「但」1/3改为「不过」1/3改为「反观」 |
| 因果 | 基于此 | 改为：从这个角度看 / 以此为前提的话 |
| 因果 | 从而 | 改为：结果就是 / 带来的结果是 |
| 递进 | 不仅……而且 | 改为：不只是……更深一层看 / 除了……还发现 |
| 结构 | 一方面……另一方面 | 删除（直接分句叙述） |

## 二、学术动词替换（高频→中频→低频，轮换使用）

| AI最爱 | 第1轮替换 | 第2轮替换 | 第3轮替换 |
|--------|----------|----------|----------|
| 分析 | 剖析 | 解构 | 往深里看 |
| 促进 | 推动 | 催化 | 加了一把力 |
| 影响 | 作用 | 塑造 | 改变……走向 |
| 表明 | 揭示 | 指向 | 说明了一个事 |
| 实现 | 达成 | 落实 | 做到了 |
| 构建 | 搭建 | 组建 | 搭起来 |
| 验证 | 证实 | 检验 | 实测确认 |
| 探讨 | 论析 | 梳理 | 过一遍 |
| 显著 | 幅度可观 | 统计学意义上 | 肉眼可见的 |
| 优化 | 调优 | 改良 | 让……更好用 |
| 提出 | 引入 | 构造 | 给出了一个 |
| 展现 | 呈现 | 表现为 | 看起来是 |

## 三、虚词删减清单

删除或大幅减少以下虚词：

| 虚词 | AI密度(每千字) | 人类密度 | 目标密度 |
|------|---------------|---------|---------|
| 的 | 45-60 | 25-35 | <35 |
| 了 | 12-18 | 5-8 | <8 |
| 是 | 15-25 | 8-12 | <12 |
| 在 | 10-15 | 4-8 | <6 |
| 和/与/及 | 8-12 | 3-6 | <5 |
| 其/此/该 | 8-15 | 2-5 | <4 |
| 等 | 5-8 | 1-3 | <2 |

## 四、模糊量化词替换表

| AI模糊词 | 替换为具体表达 |
|----------|--------------|
| 显著提升 | 提升 23.7%（或具体数值） |
| 大幅增长 | 增长 41%，从 120 升至 169 |
| 一定程度 | 部分样本中（约 34%） |
| 研究表明 | 2023 年王某等人对 450 例样本的研究表明 |
| 具有重要意义 | 对后续临床方案制定有直接参考价值 |
| 多数情况下 | 在 78% 的测试场景中 |
| 相对较好 | 比基线高 12.3 个百分点 |
| 存在一定差距 | 差值为 0.47（p<0.05） |

## 五、句首多样化要求

**强制规则**：任何一段内，相邻 3 句的句首词不能相同。且全文句首不能出现连续 2 段以相同类型词开头。

禁止连续使用的句首：本研究/本文/我们/实验/结果/通过/根据/随着/在/基于/从/以
